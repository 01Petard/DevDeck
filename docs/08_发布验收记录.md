## 签名、安全边界与清理

- `codesign -dv`：`Signature=adhoc`，无 TeamIdentifier；**未使用 Developer ID，未公证**。本机 `spctl` 评估返回 `accepted / override=security disabled`，这是已有系统策略，不是本次修改。默认 Gatekeeper 与隔离下载包的提示 **NOT RUN**，不代表可直接向公众分发。
- 权限仅 Core 默认及 Store 的 load/get/set/save/reload，移除未用 get-store；未引入 Shell、广泛文件权限、提权或新产品范围。三个自定义 IPC 不变。正式 UI 无模拟端口，fixture 只用于测试。
- TCP 是当前权限可见的快照；部分启动时间/路径可能不可读。PID 与秒级启动时间复核仍有系统竞态；不能确认退出时只报告已发送，不升级 SIGKILL。
- 仅探测显式配置的回环 HTTP(S) GET，禁止代理与重定向；HTTP 2xx 不等于业务健康。配置保存不承诺断电时原子性，不支持多个实例同时写配置。
- 临时收藏 18765/18766/18768 全部移除，现有用户配置与开始前的 JSON 内容一致、权限恢复 0600。自建测试服务已退出；18765、18766、18768 及 Vite 1420 无监听。临时配置备份与控制文件已删除，安装卷已从 Finder 推出，最终安装版已重新打开。未停止任何用户原有服务。
- 未提交或回退用户原有的 `.gitignore` 修改和 `.vscode/extensions.json` 暂存删除。
