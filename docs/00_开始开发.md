# DevDock 文档导航

DevDock 是 macOS 本机 TCP 端口工具。功能范围为监听扫描、进程元数据、搜索、端口收藏与备注、回环 HTTP 检测、安全 SIGTERM 和 DMG 打包。

当前源码版本由 `package.json`、`src-tauri/tauri.conf.json` 和 `src-tauri/Cargo.toml` 共同维护；不要从历史规格或验收记录推断当前版本。当前源码为 0.1.1，v0.1.0 安装版的验收范围与未验证项保存在发布记录中。

## 文档维护规则

- 使用说明在 README，环境、命令与排错在开发指南；不要把阶段流水继续堆入 README。
- 功能、技术和数据规格分别维护在 01–04；以实际代码和锁定依赖核对，不复制新的平行规格。
- 验收记录描述具体版本、环境和实际执行结果。历史 PASS 不自动代表新版本或其他机器已验证；新发布追加对应记录，保留旧校验值和未验证项。
- `archive/` 是历史快照，不作为当前命令入口。初始单文件规格已归档，后续维护分章节文档。
- 修改前按 [AGENTS.md](../AGENTS.md) 阅读相关规格；明确授权的局部修改直接完成，不重复要求设计批准。

## 验证边界

原生功能与 DMG 在 Mac 上验证，不以模拟数据替代。涉及终止的测试只操作本次自行创建的临时服务，不提权、不自动升级 SIGKILL。版本发布以 [Release Gate](06_测试与发布.md) 的证据判断，签名完整性不等于 Developer ID 或 Apple 公证。
